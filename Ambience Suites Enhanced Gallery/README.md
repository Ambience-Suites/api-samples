# Ambience Suites Enhanced Gallery

This is a complete clone of the organized JavaScript API samples directory, featuring a well-structured layout for easy navigation and discovery of YouTube API examples.

## 📁 Directory Structure

This directory contains organized YouTube API samples in the following categories:

### 🔐 **[authentication/](authentication/)**
OAuth and authentication utilities for YouTube API access.
- `auth.js` - Core authentication script used by all samples

### 🔍 **[search/](search/)**
Video search functionality samples.
- `search.html` - Search interface
- `search.js` - Search implementation

### 📤 **[upload/](upload/)**
Video upload samples including CORS uploads.
- `upload_video.html`, `upload_video.js`, `upload_video.css` - Complete upload interface
- `cors_upload.js` - CORS-based resumable upload

### 📋 **[playlist/](playlist/)**
Playlist management and creation samples.
- `playlist_updates.html`, `playlist_updates.js` - Playlist creation and management

### 📊 **[analytics/](analytics/)**
YouTube Analytics API samples.
- `analytics_codelab.html`, `analytics_codelab.js`, `analytics_codelab.css` - Analytics codelab
- `yt_analytics_v2.html` - YouTube Analytics v2 sample

### 🎥 **[my-uploads/](my-uploads/)**
Display user's uploaded videos.
- `my_uploads.html`, `my_uploads.js`, `my_uploads.css` - User uploads interface

### 🚀 **[quickstart/](quickstart/)**
Quick start guides and basic samples.
- `quickstart.html` - Web quickstart
- `nodejs-quickstart.js` - Node.js quickstart

### 🎬 **[enhanced-gallery/](enhanced-gallery/)**
**Ambience Suites Enhanced Gallery** - An advanced YouTube video gallery UI/UX implementation featuring:

#### Seven AI-Powered Features:
1. 🔍 **Search Assist** - Intelligent search suggestions
2. 🏷️ **Video Tagging** - Custom tag management
3. 📑 **Active List** - Bookmark system
4. ⚙️ **Presets** - User preferences
5. 💾 **Load/Download Library** - Data import/export
6. 👥 **Watch Party** - Collaborative viewing
7. ❤️ **Support Publisher** - Creator support features

See [enhanced-gallery/ENHANCED_GALLERY_README.md](enhanced-gallery/ENHANCED_GALLERY_README.md) for complete documentation.

3. **Read the code** and comments to understand the implementation
4. **Run the samples** locally (most require OAuth credentials)

## 📚 Documentation

- Each folder contains related samples with HTML, JavaScript, and CSS files
- For detailed information about each sample, see the sample-specific documentation
- For the Enhanced Gallery, see the dedicated README in the `enhanced-gallery/` folder

## 🔧 Setup

Most samples require OAuth 2.0 credentials:
1. Visit the [Google Cloud Console](https://console.cloud.google.com/)
2. Create or select a project
3. Enable the YouTube Data API v3
4. Create OAuth 2.0 credentials
5. Update the client ID in `authentication/auth.js`
