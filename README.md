api-samples
===========

Code samples for YouTube APIs, including the YouTube Data API, YouTube Analytics API, and YouTube Live Streaming API. The repo contains language-specific directories that contain the samples.

## 🎬 Featured: Ambience Suites Enhanced Gallery

The **[Ambience Suites Enhanced Gallery](Ambience%20Suites%20Enhanced%20Gallery/)** is an organized collection of YouTube API samples featuring:

- **Organized Structure**: All samples are categorized by functionality (authentication, search, upload, analytics, etc.)
- **Enhanced Gallery**: A complete YouTube gallery UI with 7 AI-powered features
- **Easy Navigation**: Well-structured folders for quick discovery

See the [Ambience Suites Enhanced Gallery README](Ambience%20Suites%20Enhanced%20Gallery/README.md) for details.

## 📂 Directory Structure

The **javascript** folder has been organized into thematic categories for better navigation:
- `authentication/` - OAuth and auth utilities
- `search/` - Video search samples
- `upload/` - Video upload examples
- `playlist/` - Playlist management
- `analytics/` - Analytics API samples
- `my-uploads/` - User uploads display
- `quickstart/` - Quick start guides
- `enhanced-gallery/` - Advanced gallery UI with AI features
