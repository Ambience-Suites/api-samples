# Quick Start Guide - Ambience Suites Enhanced Gallery

## Getting Started in 3 Easy Steps

### Step 1: Open the Gallery
Simply open `enhanced_gallery.html` in your web browser:
```bash
# Navigate to the javascript directory
cd javascript

# Open with your default browser (or open manually)
# Linux/Mac:
open enhanced_gallery.html
# Or just double-click the file in your file explorer
```

### Step 2: Explore the Features
The gallery works immediately in **demo mode** with sample videos. You can:

1. **Search Assist** - Type in the search box to see AI-powered suggestions
2. **Tag Videos** - Click any video to open it and add custom tags
3. **Bookmark Videos** - Click the bookmark icon on any video card
4. **Adjust Presets** - Navigate to Presets from the sidebar menu
5. **Create Watch Party** - Navigate to Watch Party to create or join sessions
6. **Support Publishers** - Browse featured content creators
7. **Import/Export** - Use Load/Download Library to backup your data

### Step 3: Optional - Enable Full YouTube API Access
For real YouTube search functionality:

1. Get OAuth credentials from [Google Cloud Console](https://console.cloud.google.com/)
2. Edit `auth.js` and replace `__YOUR_CLIENT_ID__` with your client ID
3. Reload the page and authorize access

## Navigation Tips

- **Sidebar Menu** - Click the menu icon or links to navigate between sections
- **Video Cards** - Click any video to view details and add tags
- **Bookmark Icon** - Quick bookmark from any video card
- **Share Icon** - Share videos via native sharing or clipboard

## Data Persistence

All your data (bookmarks, tags, presets) is automatically saved to your browser's local storage. Your data persists across sessions and is private to your browser.
